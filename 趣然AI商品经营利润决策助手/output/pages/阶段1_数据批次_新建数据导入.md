# 页面名称：新建数据导入

## 1. 文档元信息
| 字段 | 内容 |
| :--- | :--- |
| 页面 ID | `PAGE-F01-02` |
| Source IDs | `REQ-F01-01, REQ-F01-02, AC-F01-01, AC-F01-03` |
| 所属产品 | 趣然 AI 商品经营与利润决策助手 |
| 所属模块 | 数据批次 |
| 适用端 | PC Web（最小宽度 1024px） |
| 页面路由 | `/batches/new` |
| 页面类型 | 表单 |
| 所属阶段 | 阶段1(MVP) |
| 上游来源 | 批次列表 / 角色待办工作台空批次引导 |
| 下游去向 | 批次详情与校验结果 / 批次列表 |

## 2. 页面概述
### 2.1 一句话定位
让运营声明玩具事业部、完整自然月期间和冻结业务截止日，选择可读 XLSX 后建立唯一、可追溯且幂等的数据批次。

### 2.2 存在理由
1. 不显式声明期间和截止日会让历史新品分类随处理日期变化。
2. 不做文件和必填校验会发布依赖期间的错误清单。
3. 没有幂等反馈会因重复点击、重试或多窗口建立重复闭环。

### 2.3 页面目标（可衡量）
| 维度 | 指标 |
| :--- | :--- |
| 完整性 | 合法提交 100% 包含事业部、完整自然月、业务截止日和 XLSX |
| 幂等性 | 同指纹重复提交 100% 返回原 batch_id |
| 防错 | 非完整自然月、非法日期或不可读文件不发布行动清单 |

### 2.4 不做什么（范围边界）
- 不支持 CSV、在线表格、外部数据库或拖入多文件——首版仅 XLSX 单文件。
- 不自动保存含文件草稿——离开时仅提示未提交内容。
- 不下载错误文件或导出模板——无 Source IDs。
- 不让用户点击第二次“生成清单”——校验后自动处理有效 SPU。

## 3. 用户与场景
### 3.1 目标用户
| 角色 | 使用方式 |
| :--- | :--- |
| 运营 | 每周一使用办公 PC 导入数据支持部门提供的经营表 |
| 其他角色 | 无导入权限，不展示页面表单 |

### 3.2 核心使用场景
**场景 A：正常建立本周批次（主场景）**
- 时机：数据支持部门提供新经营表
- 前置：运营已登录并核对统计期间与截止日
- 动作：确认事业部 → 填写完整自然月和截止日 → 选择 XLSX → 提交
- 情绪：谨慎、确定

**场景 B：错误或重复提交恢复（兜底场景）**
- 时机：期间非法、文件不可读、网络重试或重复点击
- 前置：表单已填写或原指纹已存在
- 动作：按字段提示修正；若指纹命中则直接进入原批次详情
- 情绪：不担心重复、不丢失上下文

### 3.3 用户核心诉求（优先级排序）
1. 清楚知道本次数据代表哪个业务期间。
2. 在上传前发现可修正的日期和文件问题。
3. 重复提交不产生第二批次。
4. 提交后能持续看到校验与规则处理进度。

## 4. 信息架构
### 4.1 区域划分
1. 应用壳与面包屑；2. 口径说明；3. 批次信息表单；4. 文件选择与摘要；5. 提交/取消；6. 离开确认。

### 4.2 区域内容
- 事业部：固定选择玩具事业部。
- 数据期间：开始日、结束日、“上一个完整自然月”说明。
- 业务截止日：作为新品年龄冻结基准。
- XLSX：文件名、大小、可读状态；不展示本地路径。
- 提交摘要：提交前再次确认四项输入。

## 5. 界面内容
### 5.1 元素清单
- **事业部字段**：玩具事业部；导入开始后冻结。
- **数据期间**：起止日均必填，必须可解释为一个完整自然月。
- **业务截止日**：必填，不能早于期间结束日。
- **XLSX 文件选择**：仅接收单个可读 `.xlsx`；显示基础文件名。
- **导入并校验按钮**：所有前置校验通过后可用，提交中禁用。
- **取消**：无改动直接返回；有输入则提示离开后文件选择不会保留。

### 5.2 辅助信息
明确说明源表合计将被忽略、10—20 仅是首轮验收规模、库存或品退缺失将字段级降级而非猜值。

## 6. 交互流程
### 6.1 页面加载与初始化
校验运营权限 → 初始化玩具事业部 → 其余字段为空 → 无有效角色或非运营显示权限不足。

### 6.2 核心操作流程
```text
填写期间与截止日 + 选择 XLSX
  ├─ 前置校验失败 → 定位字段并显示可修正原因
  └─ 通过 → 确认提交摘要 → 提交并禁用重复操作
       ├─ 新指纹 → 建立 batch_id → 进入批次详情
       └─ 指纹命中 → 提示已存在 → 进入原批次详情
```

### 6.3 辅助操作
字段失焦校验；提交时全量校验；已填写字段或选文件后离开需确认。

## 7. 状态与边界
### 7.1 页面状态全景
| 状态 | 页面表现 |
| :--- | :--- |
| 初始 | 事业部就绪，其余字段待填写 |
| 输入 | 字段失焦后显示局部校验 |
| 可提交 | 四项前置条件合法，按钮可用 |
| 提交中 | 显示建立批次中，禁止重复提交 |
| 成功 / 指纹命中 | 跳转新批次或原批次详情 |
| 失败 / 无权限 | 保留非文件字段并显示恢复路径；无权不显示业务表单 |

### 7.2 边界与容错
| 边界 | 策略 |
| :--- | :--- |
| 网络异常 | 不显示成功；可重新选择文件后重试，指纹保证幂等 |
| 会话过期 | 返回钉钉认证，禁止后台继续显示经营信息 |
| 连续文件错误 | 每次显示具体文件级原因，不自动改用其他格式 |
| 异常输入 | 非完整自然月、截止日早于期间末、非 XLSX 均拦截 |
| 并发提交 | 所有同指纹请求返回第一次建立的批次 |
| 文件损坏/加密 | 建立失败状态或阻止提交，不生成清单 |

## 8. 业务规则与校验
### 8.1 字段定义
| 字段 | 说明 |
| :--- | :--- |
| `business_unit` | 阶段1固定为玩具事业部 |
| `period_start/end` | 一个完整自然月的起止日 |
| `business_date` | 建立后冻结的批次业务截止日 |
| `xlsx_file` | 数据支持部门提供的单个经营表 |

### 8.2 校验规则
| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 数据期间 | 失焦/提交 | 起止齐全、顺序合法且构成完整自然月 | “请选择一个完整自然月” |
| 业务截止日 | 失焦/提交 | 可解析且不早于期间结束日 | “业务截止日不能早于数据期间结束日” |
| 文件 | 选择/提交 | 单个可读取 XLSX | “请选择可读取的 XLSX 文件” |
| 导入权限 | 初始化/提交 | 当前角色为运营 | 权限不足 |

### 8.3 特殊业务规则
- 指纹由事业部、期间、截止日和文件内容摘要共同形成。
- 源表合计行不参与 SPU 决策；有效行数不以 10—20 作硬拒绝。
- 提交成功后输入不可修改；修正数据只能形成不同指纹的新批次。

## 9. 页面流转
### 9.1 流转图
```text
批次列表 → 本页 → 新批次详情
                 └─ 指纹命中 → 原批次详情
          └─ 取消 → 批次列表
```

### 9.2 与其他模块的关系
本页建立 F01 批次入口；字段/行校验、F02 指标和后续状态在 PAGE-F01-03 展示，唯一清单由 F05 承载。

### 9.3 扩展预案
| 方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 新文件格式 | PRD 新增 REQ/AC | 增量新增解析入口，不静默兼容 |
| 修正关系 | PRD 确认更正批次 | 增加前序 batch_id 和原因，不覆盖原批次 |

## 10. 数据需求
### 10.1 页面需要什么数据
当前角色、允许事业部、业务时区假设和可接受文件类型说明。

### 10.2 页面提交什么数据
事业部、期间起止、业务截止日、XLSX 文件内容及非敏感显示名。

### 10.3 明确排除的数据
不提交账号凭据、LiteLLM 密钥、客户端绝对路径、CSV、在线表格链接或 SKU 映射。

## 11. 验收标准
### 11.1 功能验收
| 编号 | 通过标准 |
| :--- | :--- |
| F-01 | 合法四项输入提交后建立批次并进入详情 |
| F-02 | 数据期间非法时不发布依赖期间的行动清单 |
| F-03 | 截止日建立后冻结并用于历史新品判断 |
| F-04 | 同指纹重复点击、网络重试或并发提交返回同一 batch_id |
| F-05 | 提交后自动校验和处理，无第二个生成清单动作 |

### 11.2 体验验收
| 编号 | 通过标准 |
| :--- | :--- |
| U-01 | 字段失焦显示局部错误，提交定位首个错误 |
| U-02 | 提交中按钮禁用且状态明确 |
| U-03 | 已选文件或已填字段后离开出现确认 |
| U-04 | 指纹命中明确说明“已存在”并进入原批次 |
| U-05 | 文件名只显示基础名称且口径说明可读 |

### 11.3 安全验收（产品层）
| 编号 | 通过标准 |
| :--- | :--- |
| S-01 | 非运营看不到表单且服务端拒绝导入请求 |
| S-02 | 会话失效提交不接收文件并返回钉钉认证 |
| S-03 | 页面与响应不返回客户端或服务器绝对路径 |
| S-04 | 文件错误不回显整表或内部解析堆栈 |
| S-05 | 页面不存在账号密码、角色维护或 LiteLLM 密钥入口 |
