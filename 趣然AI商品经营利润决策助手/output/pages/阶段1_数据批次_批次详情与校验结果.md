## 2. 页面概述
### 2.1 一句话定位
完整呈现一个不可变批次的口径摘要、处理进度、有效/拒绝/降级统计、行字段问题和 SPU 指标结果，解释哪些事实进入了固定规则。

### 2.2 存在理由
1. 让用户区分拒绝整行与字段级降级，避免把缺数误认为整条丢失。
2. 暴露原始位置、字段和原因，便于数据支持部门修正源表。
3. 区分清单就绪、AI 失败和批次失败，避免错误阻塞审核。

### 2.3 页面目标（可衡量）
| 维度 | 指标 |
| :--- | :--- |
| 勾稽 | 原始明细数可与有效、拒绝及忽略合计行勾稽 |
| 透明 | 100% 字段问题显示工作表/行号、字段、原因和影响范围 |
| 口径 | 指标均可见原始值、采用值、周期、状态、降级原因 |

### 2.4 不做什么（范围边界）
- 不在详情修改批次输入或源数据——批次建立后不可变。
- 不提供错误文件下载、导出或在线修表——首版无 Source IDs。
- 不用默认值、推广费用或 AI 推测补数。
- 不把库存缺失或品退未验证升级为整批失败。

## 3. 用户与场景
### 3.1 目标用户
| 角色 | 使用方式 |
| :--- | :--- |
| 运营 | 导入后持续查看处理进度，定位拒绝/降级原因 |
| 运营主管 | 审核前核对批次期间、指标口径和质量限制 |
| 采购计划 | 仅查看有权的批次状态与库存销量必要依据 |

### 3.2 核心使用场景
**场景 A：核对部分成功批次（主场景）**
- 时机：文件完成解析与指标计算
- 前置：至少一行身份有效，部分字段存在异常
- 动作：核对摘要 → 查看拒绝/降级统计 → 定位问题 → 进入唯一清单
- 情绪：清楚、可判断影响

**场景 B：处理中或导入失败恢复（兜底场景）**
- 时机：批次仍在处理、文件级失败或网络加载失败
- 前置：batch_id 已建立或访问明确批次
- 动作：查看当前阶段/文件级原因 → 刷新或返回批次列表，不重复建立批次
- 情绪：不误判、可恢复

### 3.3 用户核心诉求（优先级排序）
1. 明确批次是否能形成清单以及当前处理阶段。
2. 清楚每个错误影响整行还是单个判断。
3. 查看指标实际采用的值、期间和数据状态。
4. 在 AI 失败时仍能进入规则清单。

## 4. 信息架构
### 4.1 区域划分
1. 应用壳与面包屑；2. 批次摘要与处理状态；3. 校验统计；4. 问题明细；5. 指标结果；6. 数据限制与合计警告；7. 行动清单入口。

### 4.2 区域内容
- 摘要：batch_id、事业部、完整自然月、业务截止日、文件名、创建人/时间。
- 状态：接收、校验、规则处理、清单就绪、失败；AI 另列独立状态。
- 问题明细：源工作表、行号、SPU ID（若有）、字段、原始值摘要、原因、拒绝/降级影响。
- 指标结果：SPU 身份与销售、利润、品退、库存指标五列口径结构。

## 5. 界面内容
### 5.1 元素清单
- **处理步骤**：标明已完成、当前、失败步骤；AI 不控制清单就绪。
- **统计卡**：原始明细、有效身份、拒绝行、字段降级、警告数。
- **问题筛选**：按影响、字段、错误类型筛选，条件不改原记录。
- **指标表**：原始值/采用值/周期/状态/降级原因；可按 SPU 定位。
- **行动清单按钮**：固定规则完成后显示并进入该 batch_id 唯一清单。

### 5.2 辅助信息
明确源表合计已忽略；SPU 数量仅作首轮规模提示；业务时区按当前实现假设标注。

## 6. 交互流程
### 6.1 页面加载与初始化
校验 batch_id 与角色 → 获取裁剪后的批次快照 → 处理中定时刷新状态，终态停止 → 默认展示摘要与问题总览。

### 6.2 核心操作流程
```text
查看摘要 → 选择“问题明细”或“指标结果”
  ├─ 问题明细 → 筛选并定位源行、字段、原因和影响
  └─ 指标结果 → 查看五列口径与降级原因
规则完成 → 点击行动清单 → 进入该批次唯一清单
```

### 6.3 辅助操作
处理中可手动刷新；问题/指标筛选可清除；返回列表保留列表查询条件。

## 7. 状态与边界
### 7.1 页面状态全景
| 状态 | 页面表现 |
| :--- | :--- |
| 加载 / 处理中 | 展示已知摘要与当前步骤，不提前显示成功 |
| 全部有效 | 拒绝/降级为 0，指标口径完整 |
| 部分成功 | 有效、拒绝、降级分别可见，合法行继续处理 |
| 导入失败 | 显示文件级原因，不生成清单 |
| 清单就绪 / AI 失败 | 清单入口可用，AI 独立标记失败 |
| 加载失败 / 无权限 | 原 batch_id 上下文重试；越权不返回摘要 |

### 7.2 边界与容错
| 边界 | 策略 |
| :--- | :--- |
| 网络异常 | 保留 batch_id，原详情重试，不把失败显示成无问题 |
| 会话过期 | 返回钉钉门禁且不保留敏感详情画面 |
| 连续处理错误 | 显示最后成功步骤和文件级原因，不自动猜测完成 |
| 异常输入数据 | 身份错误拒绝行；指标错误仅停止依赖判断 |
| 并发/重复访问 | 始终读取同一批次快照，不重复触发业务处理 |
| 分母为0/周期不可信 | 不计算品退或库存天数，并显示明确状态 |

## 8. 业务规则与校验
### 8.1 字段定义
| 字段 | 说明 |
| :--- | :--- |
| `row_impact` | `rejected` 或 `field_degraded` |
| `raw_value/adopted_value` | 源值与实际参与指标/规则的值 |
| `metric_period` | 完整自然月、最近7天或最近14天 |
| `quality_status` | 有效、缺失、异常、未验证或无可计算销量 |

### 8.2 校验规则
| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 身份字段 | 导入校验 | SPU ID、名称、店铺、平台、责任运营齐全且 ID 唯一 | 拒绝行并显示原位置 |
| 月度指标 | 指标计算 | 净销售额有效；利润率直接采用表内值 | 待补数/单位异常 |
| 品退率 | 指标计算 | 最近7天、分子分母有效且分母>0 | 未校验/无可计算销量 |
| 库存天数 | 指标计算 | 库存、在途、14天销量有效且日均>0 | 数据不足/异常/无近期销售 |

### 8.3 特殊业务规则
- 源表合计不参与决策，页面汇总仅基于有效 SPU 明细。
- 上架日期、销售、利润、品退、库存异常不删除身份快照。
- 止损/清仓派生禁补不受库存字段缺失影响。

## 9. 页面流转
### 9.1 流转图
```text
新建导入/批次列表/历史追溯 → 本页 → 对应 batch_id 的行动清单 → 建议详情
                                  └→ 返回批次列表
```

### 9.2 与其他模块的关系
承载 F01 校验与 F02 指标；F03 规则完成后只提供进入 F05 唯一清单的入口，溯源复用本页历史快照。

### 9.3 扩展预案
| 方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 新指标 | 新 REQ 定义数据来源与降级 | 增加指标列，不覆盖旧快照 |
| 错误文件下载 | PRD 正式确认 | 从既有错误记录生成，不改变导入结果 |

## 10. 数据需求
### 10.1 页面需要什么数据
批次不可变摘要、处理和 AI 状态、行数统计、文件级错误、字段问题、SPU 指标快照、质量标记及唯一清单 ID。

### 10.2 页面提交什么数据
问题/指标筛选、分页和刷新请求；本页不修改批次或指标。

### 10.3 明确排除的数据
不需要当前规则重算结果、默认补数、原始整表下载、部署密钥；采购响应不含利润、推广、品退或售后。

## 11. 验收标准
### 11.1 功能验收
| 编号 | 通过标准 |
| :--- | :--- |
| F-01 | 批次摘要显示事业部、完整自然月、截止日、文件和创建信息 |
| F-02 | 身份异常行显示原位置、字段、原因并不进入计算 |
| F-03 | 指标异常保留 SPU 并仅停止依赖判断 |
| F-04 | 每个指标显示原始值、采用值、周期、状态和降级原因 |
| F-05 | 规则完成后进入唯一清单，AI 失败不禁用入口 |

### 11.2 体验验收
| 编号 | 通过标准 |
| :--- | :--- |
| U-01 | 处理中显示当前步骤且终态后停止自动刷新 |
| U-02 | 部分成功时有效、拒绝、降级分别可辨 |
| U-03 | 问题可按影响和字段筛选并定位源行 |
| U-04 | 网络失败保留明确 batch_id 并可重试 |
| U-05 | 1024px 及以上表格核心语义不截断，完整信息可查看 |

### 11.3 安全验收（产品层）
| 编号 | 通过标准 |
| :--- | :--- |
| S-01 | 未登录或越权 batch_id 不返回批次摘要和行信息 |
| S-02 | 采购详情及错误路径不出现利润、推广、品退、售后字段 |
| S-03 | 原始值摘要不暴露消费者个人信息或内部绝对路径 |
| S-04 | 文件失败不回显解析堆栈、服务配置或 deployment secret |
| S-05 | 所有详情请求和清单入口均按服务端当前角色校验 |
