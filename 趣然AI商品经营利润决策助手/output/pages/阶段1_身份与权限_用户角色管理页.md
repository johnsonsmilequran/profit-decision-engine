# PAGE-F07-03 · 用户角色管理页

## 页面目标

仅运营主管维护真实钉钉用户与业务角色映射；运营和未认证用户不得读取映射数据。

## 功能与状态

- 主管侧边栏展示“用户角色”，进入 `/admin/roles`。
- 列表读取 PostgreSQL `role_mapping`，展示显示名、完整 unionId、角色、启用状态、批准/配置人与配置时间；主管可复制 unionId 进行钉钉账号核对。
- 表单以完整 unionId、显示名、角色、启用状态和可选钉钉 User ID 新增或更新映射。
- 保存中禁止重复提交；成功刷新真实列表；非法字段、越权、自我停用/降级和最后主管保护均显示明确错误且不修改数据。
- 空状态、加载态、加载失败重试和保存失败均不可伪装成成功。

## 验收

- 主管能真实新增运营、改为主管、停用并重新启用非本人账号，刷新后数据仍存在。
- 当前主管不能停用或降级自己；最后一个有效主管不能被停用或降级。
- 运营不显示侧边栏入口，直接地址和 API 均为 403 且角色数据为 0。
- 全局账户菜单向已认证用户显示本人的完整 unionId，并提供真实退出登录；退出后旧会话立即失效并返回登录页，以便切换钉钉账号。
