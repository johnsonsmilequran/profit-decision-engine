## 2. 页面概述

### 2.1 一句话定位

用一个不可变批次上下文，集中展示导入校验、SPU 指标口径、固定规则结果和本批行动清单，让授权用户能从原始数据一路追到建议。

### 2.2 存在理由

1. 导入后需明确区分整行拒绝、字段级降级和不影响计算的警告。
2. 经营结论需同时证明指标期间、原值、质量和规则版本。
3. 历史批次不能被新数据或新规则改写。

### 2.3 页面目标（可衡量）

| 目标 | 指标 |
| :--- | :--- |
| 校验透明 | 每项异常均有源行、字段、原值、原因和是否继续计算 |
| 口径统一 | 销售、利润、品退和库存指标显示统计期间/验证状态 |
| 确定性 | 同一快照与规则版本的分类、主动作和库存动作一致 |
| 可追溯 | 每条清单可进入建议详情，批次可进入预置追溯记录 |

### 2.4 不做什么（范围边界）

- 不编辑批次、指标、规则结果或已发布清单。
- 不增加“生成清单”按钮；导入后已自动校验并运行规则。
- 不下载错误文件或原 XLSX。
- 不提供规则编辑、规则重算或 AI 重生成。
- 不向采购提供完整指标、利润、推广、品退或规则路径视图。

## 3. 用户与场景

### 3.1 目标用户

| 角色 | 主要任务 | 可见边界 |
| :--- | :--- | :--- |
| 运营 | 检查导入和建议产出 | 完整批次、校验、指标、规则和清单 |
| 运营主管 | 核对建议依据与历史 | 完整授权批次内容 |
| 采购计划 | 不以本页作为主要工作入口 | 不进入完整指标和规则视图；从清单/建议详情获取必要投影 |

### 3.2 核心使用场景

**场景 A：导入后检查处理结果（主场景）**
- 时机：运营提交每周 XLSX 后。
- 前置：批次已建立或指纹命中旧批次。
- 动作：查看顶部汇总→核对校验结果→查看指标/规则→进入建议。
- 情绪：清楚哪些数据已被使用，哪些结论因缺数降级。

**场景 B：复盘历史差异（兜底场景）**
- 时机：本周与上周对同一 SPU 结论不同。
- 前置：历史批次保留原快照和规则版本。
- 动作：从批次列表进入→查看当时期间/截止日与数据质量→进入追溯记录。
- 情绪：确认历史没有被新数据改写。

**场景 C：无法发布清单**
- 时机：批次期间非法或无可识别 SPU。
- 前置：批次进入失败。
- 动作：查看批次级错误与拒绝行→返回批次列表→重新建立新批次，不修改失败批次。
- 情绪：知道失败原因和下一步，不误以为有清单。

### 3.3 用户核心诉求（优先级）

1. **可信**：指标和规则结论能说明来源与降级。
2. **清晰**：整行拒绝、字段降级和普通警告不混淆。
3. **稳定**：处理中、失败和就绪不使用同一含混状态。
4. **可追溯**：一次点击能进入建议或批次事件。

## 4. 信息架构

### 4.1 区域划分

1. 全站导航、面包屑与身份上下文。
2. 批次标题、期间/截止日、规则版本与处理状态。
3. 有效、拒绝、降级、警告汇总。
4. 校验结果、指标与数据质量、规则结果、行动清单四个主题页签。
5. 批次追溯与返回列表入口。

### 4.2 区域内容

**校验结果**：批次级期间错误；拒绝行、字段降级、普通警告分区表格。  
**指标与数据质量**：SPU 身份、月净销售额/期间、经营准利润率/来源、近 7 日品退率/验证标记、库存可售天数/状态。  
**规则结果**：分类、唯一主动作、补货/禁补、命中阈值、依赖降级和规则版本。  
**行动清单**：本批建议、审核状态、经营/采购动作汇总与详情入口。

## 5. 界面内容

### 5.1 元素清单

| 元素 | 内容 | 数据来源 | 显示条件 |
| :--- | :--- | :--- | :--- |
| 批次身份 | 编号、事业部、文件名、导入人/时间 | 不可变批次 | 批次可见 |
| 期间口径 | 数据期间、上一完整自然月标记、业务截止日 | 批次 | 始终 |
| 处理状态 | 已接收/校验中/规则处理中/清单就绪/失败 | 批次 | 始终 |
| 汇总卡 | 有效、拒绝、降级、警告数 | 校验摘要 | 校验已开始 |
| 页签 | 四个主题视图和各自数量 | 批次投影 | 对当前角色可见 |
| 数据行 | 各主题字段与详情入口 | 快照/决策 | 对应结果存在 |
| 批次追溯 | “查看批次追溯” | 页面地图 | 用户可看该批次 |

### 5.2 辅助信息

- 本批处理使用的业务时区、规则版本和文件指纹摘要。
- 试点 10—20 个 SPU 只是验收规模提示，不是导入硬拒绝条件。
- 品退期间未验证、库存/近 14 天销量缺失时，显示对应依赖降级。

## 6. 交互流程

### 6.1 页面加载与初始化

1. 验证会话、角色和批次可见性；失败不返回批次摘要。
2. 读取不可变批次头、处理状态和校验汇总。
3. 默认进入“校验结果”；来自特定上游的合法页签参数可直达对应主题。
4. 处理中时轮询可观察状态，不因 AI 未终态将批次标为失败。

### 6.2 核心操作流程

```text
进入批次详情
  ├─ 处理中 → 显示阶段状态，已固化摘要可读
  ├─ 批次失败 → 显示批次级原因和校验结果，不发布清单
  └─ 清单就绪
       ├─ 校验结果 → 定位拒绝/降级/警告
       ├─ 指标与数据质量 → 查看口径和可用性
       ├─ 规则结果 → 查看固定结论与命中依据
       └─ 行动清单 → 点击建议 → 建议详情
```

### 6.3 辅助操作

- 切换页签、搜索 SPU、分页、返回批次列表。
- 从异常行查看其它仍可计算结果，但不在页面修改原值。
- 从批次追溯入口跳到带预置批次条件的追溯记录。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 初始加载 | 首次进入 | 保留详情框架并显示加载反馈 |
| 处理中 | 已接收/校验中/规则处理中 | 显示真实阶段，尚未就绪内容不伪造数据 |
| 清单就绪 | 规则与兜底已固化 | 四个页签按权限可用，不等待 AI |
| 批次失败 | 期间非法或无可识别 SPU | 显示原因，行动清单不发布 |
| 无有效行 | 所有行因必要身份错误被拒绝 | 显示拒绝汇总和定位，不显示规则结果 |
| 页签无结果 | 该类数据不存在 | 显示该主题的明确空状态 |
| 部分加载失败 | 某主题读取失败 | 保留已成功的批次头/其他页签，失败区可重试 |
| 无权限/对象不可见 | 会话、角色或对象权限失败 | 通用无权限路径，不显示批次摘要 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 网络异常 | 区分整页与某页签失败，保留已成功数据并可重试 |
| 会话过期 | 停止继续读取，重新登录后再评估原路由权限 |
| 连续错误/快速切换页签 | 不让旧请求结果覆盖当前页签，同一重试未完成时不重复提交 |
| 异常批次 ID/页签参数 | 服务端校验权限；对象不存在与无权统一不泄露响应 |
| 并发处理更新 | 页面只接受状态前进，不回退或覆盖已固化快照 |
| 指纹命中 | 展示第一次成功建立的批次和已有事件，不创建副本 |
| 品退期间未验证 | 标为未验证并阻止依赖该值的观察/加投，不删除其他结果 |
| 库存或近 14 日销量缺失 | 不生成补货；清仓/止损仍原子生成禁补 |
| 上架日期无法解析 | 分类和依赖动作降级，保留原行错误 |
| 采购修改 URL 进入 | 不返回完整指标/规则视图与受限字段，引导回自身行动清单 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| `batch_id` | 批次稳定 ID |
| `business_unit` | 试点事业部 |
| `period_start/end` | 本批销售、利润与费用使用期间 |
| `business_cutoff_date` | 新品年龄和上一完整自然月计算基准 |
| `rule_version` | 产生决策的固定规则版本 |
| `row_number/field/raw_value` | 校验问题的原行定位 |
| `quality_level` | 拒绝行/字段降级/警告 |
| `continued_computation` | 该异常后是否仍计算其他结果 |
| `metric_period/verified` | 指标统计期间与口径验证状态 |

### 8.2 校验规则

| 校验项 | 规则 | 失败表现 |
| :--- | :--- | :--- |
| 批次期间 | 存在、起止合法并可解释为完整自然月 | 批次失败，不发布清单 |
| SPU 身份 | ID、链接/名称、店铺、平台、责任运营完整且批次内 ID 唯一 | 对应行拒绝 |
| 业务指标 | 按依赖单独校验 | 只停止依赖该字段的结论 |
| 表头/汇总行 | 不得作为 SPU 输入 | 标记并排除，不发布决策 |
| 历史查看 | 使用批次原期间、截止日和规则版本 | 不使用访问日或当前规则重算 |

### 8.3 特殊业务规则

- 同指纹重复导入只返回原批次和原事件链。
- 月净销售额使用上一完整自然月；经营准利润率采用表内值不重算旧公式。
- 近 7 日品退率必须保留期间与 verified；未证明时按缺失降级。
- 清仓/止损与禁补在同一决策中原子生成；缺库存时不猜补货。
- 固定规则结果先于 AI 解释就绪，AI 失败不改变批次成功状态。

## 9. 页面流转

### 9.1 流转图

```text
数据批次列表 ──批次行──┐
新建数据导入 ──提交/命中─├─→ 数据批次详情（本页）
建议详情 ──来源批次────┘          │
                                               ├─ 建议行 → 建议详情
                                               └─ 批次追溯 → 追溯记录
```

### 9.2 与其他模块的关系

- 导入页负责建立批次；本页只读展示处理与产出。
- 建议详情承载单 SPU 审核与执行；本页不更改建议状态。
- 追溯记录承载事件查询；本页只提供批次上下文入口。
- 采购工作流以行动清单和裁剪建议详情为主，不因本页扩权。

### 9.3 扩展预案

| 扩展方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 自动数据源 | 外部数据源、账号、网络、映射与责任正式确认 | 复用批次和校验投影，不改变不可变语义 |
| 新证据源 | 评价/退款/广告明细正式立项 | 以新的可追溯证据区扩展，不伪装成 MVP 汇总值 |
| SKU 粒度 | SKU 数据、聚合/分摊、规则和责任人重新立项 | 新建 SKU 批次投影，保留 MVP SPU 历史不变 |

## 10. 数据需求

### 10.1 页面需要什么数据

| 数据 | 来源 | 用途 |
| :--- | :--- | :--- |
| 批次头与处理状态 | 导入批次 | 标识唯一上下文与处理阶段 |
| 校验摘要与问题行 | 校验结果 | 分区展示拒绝、降级和警告 |
| SPU 指标与质量 | 批次快照 | 展示销售、利润、品退、库存口径 |
| 规则结果 | 决策记录 | 展示分类、主动作、库存动作和命中依据 |
| 行动清单投影 | 本批建议/动作 | 进入单条建议与展示只读汇总 |
| 当前身份与角色 | 钉钉认证/IT 映射 | 决定页面与字段可见性 |

### 10.2 页面提交什么数据

| 数据 | 触发时机 | 用途 |
| :--- | :--- | :--- |
| 当前页签、SPU 搜索、页码/每页数 | 查看不同主题 | 读取本批只读投影 |
| 建议引用 | 点击清单行 | 进入建议详情 |
| 批次引用 | 点击追溯 | 进入预置追溯记录 |

### 10.3 明确排除的数据

- 不提交原 XLSX 编辑、错误文件下载或批次删除请求。
- 不提交规则阈值或决策结果修改。
- 不提交审核、执行或结果状态变更。
- 不向采购请求完整利润、推广、品退或规则路径。
- 不请求 LiteLLM 或钉钉凭据。

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 批次身份 | 页面展示事业部、期间、业务截止日、文件名、指纹摘要、导入人/时间 |
| F-02 | 重复指纹 | 同指纹访问返回原批次和原清单，不出现第二事件链 |
| F-03 | 校验分区 | 拒绝行、字段降级、普通警告分区显示并包含源行/字段/原值/原因/是否继续 |

| F-06 | 清单跳转 | 点击建议行进入正确建议详情，批次追溯带入当前批次 |
| F-07 | 降级继续 | 某指标异常仅停止依赖该值的判定，其他可确定结果仍展示 |

### 11.2 体验验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| U-01 | 状态可辨 | 处理中、批次失败、无有效行、页签无结果和加载失败表达不混淆 |
| U-02 | 主题导航 | 四个页签名称、数量和当前主题清楚，切换不改写批次 |
| U-03 | 密集数据阅读 | 1280px 及以上能保留关键固定列并水平查看其他字段 |
| U-04 | 上下文保留 | 从建议/追溯返回后保留原页签、搜索与页码 |
| U-05 | 失败可恢复 | 某页签失败时已成功批次头和其他页签仍可读，失败区可单独重试 |
| U-06 | 错误可定位 | 校验问题可按源行和字段找回数据支持部门的原数据 |

### 11.3 安全验收（产品层）

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
