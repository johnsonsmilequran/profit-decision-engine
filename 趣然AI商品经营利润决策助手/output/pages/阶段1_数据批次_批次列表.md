# 页面名称：批次列表

## 1. 文档元信息
| 字段 | 内容 |
| :--- | :--- |
| 页面 ID | `PAGE-F01-01` |
| Source IDs | `REQ-F01-01, REQ-F01-02, REQ-F05-01, AC-F01-02, AC-F05-02` |
| 所属产品 | 趣然 AI 商品经营与利润决策助手 |
| 所属模块 | 数据批次 |
| 适用端 | PC Web（最小宽度 1024px） |
| 页面路由 | `/batches` |
| 页面类型 | 列表 |
| 所属阶段 | 阶段1(MVP) |
| 上游来源 | 左侧导航 / 角色待办工作台 / 历史追溯索引 |
| 下游去向 | 新建数据导入、批次详情与校验结果、行动清单列表 |

## 2. 页面概述
### 2.1 一句话定位
按时间分页查看不可变业务批次及其处理、校验、规则、AI 和清单状态，并进入对应真实批次或清单。

### 2.2 存在理由
1. 避免新导入覆盖旧清单及已有审核、动作和结果。
2. 让重复指纹命中时回到原批次，而非产生第二套身份。
3. 区分规则清单就绪与 AI 独立状态，避免 AI 失败被误判为整批失败。

### 2.3 页面目标（可衡量）
| 维度 | 指标 |
| :--- | :--- |
| 唯一性 | 每个 `batch_id` 仅出现一条批次记录 |
| 可追溯 | 100% 批次显示事业部、期间、业务截止日与创建信息 |
| 可达 | 任一批次 1 次点击进入详情或其唯一清单 |

### 2.4 不做什么（范围边界）
- 不删除、覆盖或合并历史批次——历史快照必须保留。
- 不提供导出、批量操作或无限滚动——无 Source IDs。
- 不把 10—20 个 SPU 设为批次合法硬门槛。
- 不在列表展示原始文件内容或行字段错误全文——由详情页承载。

## 3. 用户与场景
### 3.1 目标用户
| 角色 | 使用方式 |
| :--- | :--- |
| 运营 | 周一检查导入结果、重试后定位原批次并新建导入 |
| 运营主管 | 查找最新或历史批次与对应清单 |
| 采购计划 | 仅查看有权批次/清单入口，不见受限经营字段 |

### 3.2 核心使用场景
**场景 A：定位最新批次（主场景）**
- 时机：用户进入数据批次
- 前置：至少存在一个当前角色可见批次
- 动作：核对期间和截止日 → 查看状态 → 进入详情或清单
- 情绪：确定、可追溯

**场景 B：重复上传后返回原批次（兜底场景）**
- 时机：同一指纹因重试或并发提交命中
- 前置：原批次已建立
- 动作：收到“已存在”提示 → 列表定位原批次 → 查看既有状态链
- 情绪：安心、不担心重复执行

### 3.3 用户核心诉求（优先级排序）
1. 快速判断哪个批次是最新业务事实。
2. 确认处理到哪一步且清单是否可审核。
3. 找回历史批次而不被新数据覆盖。
4. 重复请求始终回到同一批次。

## 4. 信息架构
### 4.1 区域划分
1. 应用壳与面包屑；2. 标题与新建入口；3. 检索/状态筛选；4. 批次表格；5. 分页；6. 指纹命中反馈。

### 4.2 区域内容
- 筛选：事业部、期间、批次/文件名关键词、处理状态。
- 表格：批次 ID、事业部、数据期间、业务截止日、有效/拒绝/降级数、校验/规则/AI/清单状态、创建人、创建时间、详情与清单入口。
- 新建入口仅运营显示。

## 5. 界面内容
### 5.1 元素清单
- **新建数据导入**：运营可见；进入新建页。
- **状态筛选**：筛选不改变批次内容，条件写入 URL。
- **批次行**：显示不可变摘要；点击进入批次详情。
- **行动清单入口**：固定规则完成且唯一清单可用时显示。
- **AI 状态**：待生成/生成中/已生成/失败，独立于清单状态。
- **分页器**：服务端分页，页码、总数与每页数量明确。

### 5.2 辅助信息
首轮规模仅显示“符合/超出首轮验收规模”提示；文件名只显示基础名称，不显示本地路径。

## 6. 交互流程
### 6.1 页面加载与初始化
读取 URL 筛选和页码 → 校验当前角色 → 获取裁剪后的批次分页 → 默认按创建时间降序。

### 6.2 核心操作流程
```text
筛选/搜索 → 服务端返回匹配批次 → 选择批次 → 进入详情
规则完成 → 点击唯一清单入口 → 进入对应 batch_id 的行动清单
运营点击新建 → 进入新建数据导入
```

### 6.3 辅助操作
清除筛选回到第一页；浏览器前进/后退恢复 URL 中筛选与页码。

## 7. 状态与边界
### 7.1 页面状态全景
| 状态 | 页面表现 |
| :--- | :--- |
| 初始 / 加载 | 保留筛选结构，列表显示加载中 |
| 正常 | 批次分页及各独立状态完整显示 |
| 空列表 | 运营可前往导入；其他角色仅显示暂无批次 |
| 筛选无结果 | 显示当前条件无匹配并可清除筛选 |
| 处理中 | 显示当前阶段，禁用未就绪清单入口 |
| 加载失败 / 无权限 | 显示重试或权限不足，不呈现伪空列表 |

### 7.2 边界与容错
| 边界 | 策略 |
| :--- | :--- |
| 网络异常 | 保留筛选与页码，提供原条件重试 |
| 会话过期 | 返回钉钉门禁，不返回批次记录 |
| 连续加载错误 | 显示失败时间和重试，不自动创建新查询条件 |
| 异常筛选输入 | 忽略非法页码并回第一页；未知状态提示条件无效 |
| 并发新批次 | 刷新后按稳定排序展示，不改变已打开 batch_id |
| 指纹重复 | 返回原批次并高亮定位，不增加列表记录 |

## 8. 业务规则与校验
### 8.1 字段定义
| 字段 | 说明 |
| :--- | :--- |
| `batch_id` | 全局唯一且不可变的批次标识 |
| `period_start/end` | 本批次完整自然月期间 |
| `business_date` | 冻结的业务截止日 |
| `batch_status` | 接收、校验、规则、清单就绪或失败 |
| `ai_status` | 与批次独立的解释状态 |

### 8.2 校验规则
| 校验 | 时机 | 失败反馈 |
| :--- | :--- | :--- |
| 页码有效 | 查询时 | 回第一页并更新 URL |
| 状态筛选受支持 | 查询时 | 提示筛选值无效 |
| 批次访问权 | 打开详情 | 权限不足且不返回字段 |
| 清单已就绪 | 点击清单 | 显示当前处理阶段 |

### 8.3 特殊业务规则
- 批次指纹命中不创建新批次、建议或事件。
- 新批次不得覆盖旧批次及其审核、动作和结果记录。
- AI 失败不改变已就绪清单的可审核性。

## 9. 页面流转
### 9.1 流转图
```text
工作台/历史追溯 → 本页 → 新建导入 → 批次详情 → 唯一行动清单
                         └────────→ 历史批次详情
```

### 9.2 与其他模块的关系
本页是 F01 批次索引并承载 F05 历史保留；字段错误、指标与处理详情由 PAGE-F01-03 展示。

### 9.3 扩展预案
| 方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 修正批次关系 | 新增正式 REQ | 增加前序批次关联，不覆盖原批次 |
| 更大规模历史 | 数据量实际增长 | 保持 batch_id 与服务端分页，不改变业务身份 |

## 10. 数据需求
### 10.1 页面需要什么数据
裁剪后的批次摘要、处理/AI/清单状态、行统计、创建信息、分页总数和筛选候选项。

### 10.2 页面提交什么数据
搜索词、筛选、排序、页码；本页不提交业务状态。

### 10.3 明确排除的数据
不需要 XLSX 原始内容、行级原值、LiteLLM 密钥、完整审核/动作事件；采购返回不含利润、推广、品退和售后。

## 11. 验收标准
### 11.1 功能验收
| 编号 | 通过标准 |
| :--- | :--- |
| F-01 | 批次分页显示期间、截止日、状态和创建信息 |
| F-02 | 同指纹重复导入后仅有一条 batch_id 记录并定位原批次 |
| F-03 | 新批次出现后历史批次及清单入口仍可访问 |
| F-04 | 规则清单状态与 AI 状态独立展示 |
| F-05 | 仅运营可见新建入口，清单未就绪时不可误入 |

### 11.2 体验验收
| 编号 | 通过标准 |
| :--- | :--- |
| U-01 | 筛选、页码写入 URL，刷新和前进后退可恢复 |
| U-02 | 加载失败不显示为空列表且可原条件重试 |
| U-03 | 筛选无结果可一键清除筛选 |
| U-04 | 文件名不显示本地绝对路径 |
| U-05 | 1024px 及以上批次关键语义可读且详情可达 |

### 11.3 安全验收（产品层）
| 编号 | 通过标准 |
| :--- | :--- |
| S-01 | 未登录请求不返回批次列表数据 |
| S-02 | 无权角色看不到新建入口且提交导入被服务端拒绝 |
| S-03 | 越权 batch_id 不返回批次摘要 |
| S-04 | 采购列表与错误路径不出现受限经营字段 |
| S-05 | 页面、文件名和错误信息均不返回部署密钥或服务器路径 |
