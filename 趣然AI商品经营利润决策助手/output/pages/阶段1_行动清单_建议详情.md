## 2. 页面概述
### 2.1 一句话定位
以一条 SPU 整体建议为中心，固化展示四要素、利润—库存双轨规则结论、指标/规则快照、AI 独立解释、整体审核、分动作执行结果和裁剪时间线。

### 2.2 存在理由
1. 没有共同详情，主管可能拆开审核经营和采购动作，破坏原子结论。
2. 不同时显示利润与库存轨道，会隐藏运营已止损而采购仍待禁补的卡点。
3. 没有固化快照和追加事件，后续规则/源表变化会覆盖当时依据。

### 2.3 页面目标（可衡量）
| 维度 | 指标 |
| :--- | :--- |
| 四要素 | 100% 建议包含对象、问题、关键依据和推荐动作 |
| 追溯 | 100% 展示批次、期间、截止日、规则版本、关键值和生成时间 |
| 状态准确 | 审核状态与各动作状态分层展示且不互相覆盖 |

### 2.4 不做什么（范围边界）
- 不允许编辑商品类型、主动作、补货结论、阈值或历史快照。
- 不提供普通用户 AI 重试、模型切换、解释版本或密钥入口。
- 不自动修改广告、采购或库存系统；人工记录不冒充外部回执。
- 不推断广告明细、评价主题、退款原因或 SKU 结论。

## 3. 用户与场景
### 3.1 目标用户
| 角色 | 使用方式 |
| :--- | :--- |
| 运营主管 | 查看完整依据并对整条待审核建议一次通过/驳回 |
| 运营 | 查看完整经营信息，执行经营动作并记录后续结果 |
| 采购计划 | 仅查看有权补货/禁补任务和库存销量必要依据并执行 |

### 3.2 核心使用场景
**场景 A：主管审核双轨建议（主场景）**
- 时机：建议待审核且规则清单已就绪
- 前置：主管有权查看完整建议
- 动作：核对对象与依据 → 查看双轨规则节点 → 进入整条建议审核表单
- 情绪：审慎、可信

**场景 B：AI 失败或并发状态已变化（兜底场景）**
- 时机：LiteLLM 失败、另一用户已更新审核/动作状态或用户越权直达
- 前置：固定规则快照存在
- 动作：继续使用结构化四要素；状态刷新后按最新 version 决策；无权则退出
- 情绪：不被阻塞、避免误操作

### 3.3 用户核心诉求（优先级排序）
1. 明确系统为何对该 SPU 给出当前唯一动作。
2. 同时看到经营与库存动作、负责人和真实进度。
3. 只开放当前角色、当前状态允许的操作。
4. 历史依据不随当前规则或新批次改变。

## 4. 信息架构
### 4.1 区域划分
1. 应用壳与面包屑；2. SPU 身份与建议状态；3. 四要素摘要；4. 利润—库存双轨决策带；5. 指标与触发规则；6. AI 解释；7. 审核与分动作进度；8. 结果；9. 溯源与时间线；10. 角色操作区。

### 4.2 区域内容
- 四要素：具体对象、发现问题、关键依据、推荐动作。
- 双轨带：共同规则节点连接经营主动作与补货/禁补，分别显示 owner 与状态。
- 快照：原始值、采用值、周期、阈值、比较、质量状态与规则版本。
- 时间线：成功审核、执行、结果事件；有权用户另见冲突/越权审计，采购仍裁剪。

## 5. 界面内容
### 5.1 元素清单
- **SPU 身份**：ID、名称、店铺、平台、责任运营；采购仅在有任务关联时返回。
- **商品类型/动作**：唯一分类、唯一主动作、补货结论，只读。
- **结构化四要素**：AI 失败也始终存在。
- **关键依据表**：指标值、周期、阈值、比较关系和限制。
- **AI 模块**：待生成/生成中/成功/失败/越界舍弃；视觉与规则结论分离。
- **审核与动作卡**：审核状态，经营/采购动作 owner、状态、version 与入口。
- **结果卡**：经营或采购人工结果；明确不是外部系统回执。
- **时间线**：前后状态、操作者、时间、备注，按角色裁剪。

### 5.2 辅助信息
显示批次 ID、事业部、数据期间、业务截止日、规则版本、生成时间和当前实现时区说明。

## 6. 交互流程
### 6.1 页面加载与初始化
校验 decision_id、任务关联和当前角色 → 获取服务端裁剪详情 → 定位审核与动作当前 version → 只显示合法操作入口。

### 6.2 核心操作流程
```text
核对四要素与双轨依据
  ├─ 主管 + 待审核 → 进入整条建议审核表单
  ├─ 运营 + 已通过/待执行 → 进入经营动作执行或结果表单
  ├─ 采购 + 有任务/待执行 → 进入采购动作执行表单
  └─ 其他状态 → 只读查看历史与最新状态
表单成功 → 返回本页并刷新时间线和 version
```

### 6.3 辅助操作
返回清单保留 batch_id 与筛选；时间线按层级筛选；AI 状态刷新不改变审核/动作区域。

## 7. 状态与边界
### 7.1 页面状态全景
| 状态 | 页面表现 |
| :--- | :--- |
| 加载 | 保留应用壳，不预显业务对象 |
| 待审核 | 双轨动作只读待激活，主管可进入审核 |
| 已驳回 | 显示驳回原因，动作关闭且快照保留 |
| 已通过/执行中 | 两动作分别显示待执行、已执行或已记录结果 |
| AI 失败 | 四要素与规则完整，AI 独立显示失败 |
| 冲突/无权限/加载失败 | 刷新最新状态；越权不返回建议身份或状态 |

### 7.2 边界与容错
| 边界 | 策略 |
| :--- | :--- |
| 网络异常 | 保留 decision_id 导航上下文并重试，不误显示空详情 |
| 会话过期 | 返回钉钉门禁且不渲染缓存经营字段 |
| 连续 AI 错误 | 持续显示结构化兜底，不开放普通用户重试 |
| 异常/缺失指标 | 显示降级原因，不补默认值或推断动作 |
| 并发状态更新 | 表单 version 冲突不覆盖；返回本页显示最新操作者/状态 |
| 采购无任务关联 | 权限不足且不返回 SPU 身份、建议状态或受限字段 |

## 8. 业务规则与校验
### 8.1 字段定义
| 字段 | 说明 |
| :--- | :--- |
| `decision_id` | 一条 SPU 整体建议稳定标识 |
| `category/main_action/replenishment_action` | 固定规则只读结果 |
| `review_state/version` | 建议级状态与并发版本 |
| `action_items` | 经营与库存动作槽位，各有 owner、状态、version |
| `key_input_snapshot` | 实际值、周期、阈值、有效性和触发规则快照 |

### 8.2 校验规则
| 校验 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 建议访问权 | 初始化 | 角色有整体信息权或采购任务关联 | 权限不足，不返回对象 |
| 操作角色/状态 | 打开表单 | 角色与状态匹配 | 操作不可用及原因 |
| version | 提交时 | 与当前审核/动作版本一致 | 状态已变化并刷新 |
| 快照完整 | 展示追溯 | 批次/规则/关键值均来自生成时固化 | 标记追溯不完整 |

### 8.3 特殊业务规则
- 主动作按清仓＞止损＞观察＞加投＞维持唯一化；AI 与人工均不可改写。
- 止损/清仓与禁补同一规则节点、同一整体审核并同时激活。
- 双动作状态独立；任一未完成时总览不得显示全部完成。

## 9. 页面流转
### 9.1 流转图
```text
工作台/行动清单/历史追溯 → 本页 → 审核表单 / 经营执行 / 采购执行 / 经营结果
                                      └─ 成功或冲突 → 返回本页刷新
```

### 9.2 与其他模块的关系
汇合 F03 规则、F04 AI、F06 审核执行、F08 溯源，并按 F07 裁剪；批次级问题回到 PAGE-F01-03。

### 9.3 扩展预案
| 方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 明细洞察 | 阶段2具备数据与稳定 REQ | 挂接 batch/spu/decision，不改快照 |

## 10. 数据需求
### 10.1 页面需要什么数据
裁剪后的 SPU 身份、批次/规则快照、四要素、双轨动作、AI 状态/解释、审核与分动作状态、结果和追加事件。

### 10.2 页面提交什么数据
本页只提交刷新和时间线筛选；业务提交由独立表单携带 decision/action ID 与当前 version 完成。

### 10.3 明确排除的数据
不需要当前源表覆盖值、当前规则重算结果、部署密钥或消费者 PII；采购不需要利润、推广、品退、售后和完整 AI 文本。

### 10.4 实施同步
生产 API 已实现 `GET /api/decisions/:decisionId`。主管与运营响应包含冻结批次、指标口径、规则版本、四要素、AI 独立状态、审核版本、双轨动作与完整追加时间线；采购必须存在库存动作关联，响应采用独立安全查询，仅返回 SPU 基础身份、库存销量必要依据、库存动作版本/结果及与该库存动作直接关联的时间线，不读取或返回利润、经营动作、审核和完整 AI 字段。React 页面 `/decisions/:decisionId` 已实现对应的完整视图与采购最小视图；当前仅展示事实状态，不在 F06 表单完成前提供审核、执行或结果假入口。1024px 开发期浏览器检查确认四要素、双轨和指标均可见且整页无横向溢出。
