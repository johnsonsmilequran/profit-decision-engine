# 页面名称：权限不足

## 1. 文档元信息
| 字段 | 内容 |
| :--- | :--- |
| 页面 ID | `PAGE-F07-02` |
| Source IDs | `REQ-F07-01, REQ-F07-02, AC-F07-01, AC-F07-02, AC-F07-03, AC-F07-04` |
| 所属产品 | 趣然 AI 商品经营与利润决策助手 |
| 所属模块 | 身份权限 |
| 适用端 | Web（PC，最小宽度 1024px） |
| 页面路由 | `/forbidden`（应用壳内状态） |
| 页面类型 | 门禁 |
| 所属阶段 | 阶段1(MVP) |
| 上游来源 | 越权页面/接口直达或无对象访问权 |
| 下游去向 | 返回上一页或进入当前角色工作台 |

## 2. 页面概述
### 2.1 一句话定位
在用户越权直达时，以应用壳内拒绝状态安全终止访问，而不泄露目标建议是否存在、身份或状态。
### 2.2 存在理由
1. 隐藏按钮不能阻止直接地址或接口访问。
2. 差异化错误可能泄露建议存在性与受限字段。
3. 用户需要安全且清晰的返回路径。
### 2.3 页面目标（可衡量）
| 维度 | 指标 |
| :--- | :--- |
| 零泄露 | 拒绝页面/接口中目标身份、状态、经营字段出现次数 0 |
| 一致拒绝 | 页面、筛选、接口、错误与审计详情旁路成功数 0 |
| 可恢复 | 100% 提供返回或当前角色工作台入口 |
### 2.4 不做什么（范围边界）
- 不说明目标对象存在与否、SPU 名称、建议状态或拒绝细节。
- 不展示申请权限或角色自助管理入口。
- 不把采购自动切换成运营角色。
- 不将登录态失效混为权限不足——失效返回钉钉门禁。

## 3. 用户与场景
### 3.1 目标用户
| 维度 | 描述 |
| :--- | :--- |
| 角色 | 已登录但无目标访问/操作权限的任一业务角色 |
| 技术熟练度 | 中等 |
| 设备/姿势 | PC，通过旧链接、收藏或手输地址访问 |
### 3.2 核心使用场景
**场景 A：采购打开无关联建议（主场景）**
- 时机：从旧消息直接打开；前置：已登录但建议无分配给当前采购角色的任务；动作：看到通用拒绝状态并返回采购待办；情绪：明确被拒绝但不接触敏感信息。

**场景 B：角色可操作范围已变化（兜底场景）**
- 时机：页面停留期间角色或对象授权变化；前置：提交/刷新时服务端拒绝；动作：进入本状态并返回当前角色工作台；情绪：安全、知道如何继续。
### 3.3 用户核心诉求（优先级排序）
1. 明白当前账号不能访问该内容。
2. 可快速回到自己有权处理的任务。
3. 不看到令人困惑或敏感的对象细节。

## 4. 信息架构
### 4.1 区域划分
1. 保留的应用壳与当前角色；2. 通用拒绝主状态；3. 简短恢复说明；4. 返回/工作台操作。
### 4.2 区域内容
- 应用壳仅保留当前角色本已有权导航。
- 主状态：“权限不足”“当前角色无法访问此内容”。
- 操作：“返回上一页”“回到我的工作台”。

## 5. 界面内容
### 5.1 元素清单
| 元素 | 内容/文案 | 数据来源 | 显示条件 |
| :--- | :--- | :--- | :--- |
| 拒绝图标 | 锁/盾牌矢量图标 | 图标库 | 始终 |
| 标题 | “权限不足” | 固定安全文案 | 始终 |
| 说明 | “当前业务角色无法访问此内容。” | 固定安全文案 | 始终 |
| 返回按钮 | “返回上一页” | 浏览历史 | 有安全上一页 |
| 工作台按钮 | “回到我的工作台” | 当前角色导航 | 始终 |
### 5.2 辅助信息
- 可提示“如职责发生变化，请按公司流程联系 IT”，不显示具体目标权限或对象。

## 6. 交互流程
### 6.1 页面加载与初始化
- 服务端先拒绝并返回通用状态；前端不得从旧缓存继续渲染目标业务对象。
- 校验会话仍有效；失效则改去钉钉门禁。
### 6.2 核心操作流程
```text
访问受限目标 → 服务端默认拒绝并记录安全审计 → 清除目标视图 → 通用权限不足
  ├─ 返回上一安全页面
  └─ 回到当前角色工作台
```
### 6.3 辅助操作
- 浏览器返回若仍是受限路径，则直接去工作台，防止拒绝循环。
- 不提供“重试读取”或切换角色按钮。

## 7. 状态与边界
### 7.1 页面状态全景
| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 初始态 | 收到拒绝 | 立即展示通用拒绝文案 |
| 输入态 | 不适用 | 无表单 |
| 提交态 | 点击导航 | 按钮显示导航中，防重复 |
| 成功态 | 到达安全页面 | 结束拒绝状态 |
| 失败态 | 安全导航失败 | 仍不显示目标数据，可重回工作台 |
| 异常态 | 会话失效/网络异常 | 会话失效去门禁；网络异常保留通用状态 |
### 7.2 边界与容错
| 边界场景 | 处理策略 |
| :--- | :--- |
| 网络异常 | 使用通用本地拒绝文案，不尝试显示缓存目标 |
| 会话过期 | 转钉钉认证，不暴露先前目标 |
| 连续越权 | 每次服务端拒绝并审计，文案不逐次暴露细节 |
| 异常目标 ID | 与无权目标使用同类安全文案 |
| 授权并发变化 | 以服务端最新角色/对象关联为准 |
| 返回形成循环 | 检测后回当前角色工作台 |

## 8. 业务规则与校验
### 8.1 字段定义
| 字段 | 说明 |
| :--- | :--- |
| `current_role` | 仅用于渲染已有权应用壳，不含目标数据 |
| `safe_return` | 经过校验的上一页或角色工作台路径 |
| `correlation_id` | 可供支持定位的非业务敏感请求引用（若系统提供） |
### 8.2 校验规则
| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 会话 | 初始化 | 有效；否则去认证门禁 | 不在本页说明目标 |
| safe_return | 导航前 | 必须为当前角色有权站内路径 | 非法则回工作台 |
| 目标响应 | 任一拒绝 | 不含目标身份、状态及受限字段 | 固定通用拒绝文案 |
### 8.3 特殊业务规则
- 服务端默认拒绝；按钮隐藏不是安全边界。
- 采购请求利润、推广、品退、售后时，页面、接口、错误和审计详情均零返回。

## 9. 页面流转
### 9.1 流转图
`任一受限路径 → 权限不足（本页） → 安全上一页 / 当前角色工作台`；会话失效则去钉钉门禁。
### 9.2 与其他模块的关系
- F01—F08 任一资源读取或操作均可落到本安全状态。
- 越权拒绝进入安全审计；业务时间线不向无权用户披露。
### 9.3 扩展预案
| 方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 权限申请 | PRD 明确申请、审批责任与 AC | 新建独立流程，不在拒绝页静默赋权 |

## 10. 数据需求
### 10.1 页面需要什么数据
| 数据 | 来源 | 用途 |
| :--- | :--- | :--- |
| 会话有效性、当前角色 | 安全会话 | 决定门禁/应用壳 |
| 安全返回路径 | 路由安全上下文 | 恢复导航 |
### 10.2 页面提交什么数据
- 不提交业务数据；导航仅携带经校验的站内去向。
### 10.3 明确排除的数据
- 排除目标对象身份、存在性、状态、利润、推广、品退、售后、规则和审计详情。

## 11. 验收标准
### 11.1 功能验收
| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 通用拒绝 | 越权页面与操作均进入拒绝且业务状态不变 |
| F-02 | 无关联采购 | 无任务关联时不返回建议身份或状态 |
| F-03 | 安全返回 | 可返回有权上一页或角色工作台 |
| F-04 | 会话分流 | 会话失效进入钉钉门禁而非继续本页 |
| F-05 | 审计记录 | 越权拒绝记录安全审计但不进入无权业务时间线 |
### 11.2 体验验收
| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| U-01 | 文案明确 | 清楚说明当前角色无法访问，不出现技术堆栈 |
| U-02 | 恢复聚焦 | 主操作回当前角色工作台 |
| U-03 | 无拒绝循环 | 返回仍受限时自动去工作台 |
| U-04 | 应用一致 | 保留当前角色已有权应用壳风格 |
| U-05 | 网络容错 | 断网时仍保持安全拒绝且不展示缓存目标 |
### 11.3 安全验收（产品层）
| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| S-01 | 对象不可枚举 | 不同存在/不存在/无权目标的外显信息不泄露差异 |
| S-02 | 字段零泄露 | DOM、接口、错误均无受限业务字段 |
| S-03 | 服务端拒绝 | 直接接口请求不能绕过页面限制 |
| S-04 | 缓存清理 | 角色变更后旧目标内容不继续渲染 |
| S-05 | 默认拒绝 | 无明确授权始终拒绝，不自动切换/赋予角色 |

## 12. 生产实现映射

- 前端路由：`apps/web/src/pages/ForbiddenPage.tsx`，由 `apps/web/src/router.tsx` 在真实会话有效时渲染；无会话先返回钉钉门禁。
- 应用壳：`apps/web/src/components/AppShell.tsx` 只使用 `/api/auth/me` 返回的当前用户与角色，不读取或渲染受限目标对象。
- 页面保持通用拒绝文案、安全返回和当前角色工作台入口，不提供重试读取、切换角色或权限自助申请。
