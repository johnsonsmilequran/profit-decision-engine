## 2. 页面概述

### 2.1 一句话定位

在用户无有效业务角色、无权访问当前内容或登录态失效时统一阻断业务数据访问，并给出安全、可执行的恢复方向；拒绝结果不得暴露受限对象是否存在及其任何经营信息。

### 2.2 存在理由

1. 若越权直链仍返回对象摘要、状态或差异化错误，采购计划或其他未授权用户可据此推断受限建议和历史记录。
2. 若无有效角色映射仍可进入业务页，系统可能把未知身份错误地当成运营角色，破坏默认拒绝原则。
3. 若拒绝后没有返回工作台、重新登录或联系 IT 的恢复路径，合法用户无法区分登录态问题与权限配置问题。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 权限阻断 | 无角色映射、无访问权或会话失效时，100% 不进入目标业务页 |
| 数据最小可见 | 拒绝页面及其错误路径中，受限对象身份、状态、利润、推广、品退和售后字段出现数为 0 |
| 恢复可达 | 每种拒绝原因至少提供一个当前可用的恢复动作：返回工作台、重新登录或联系 IT |
| 结果一致 | 同一权限条件经页面入口、直链或历史入口访问时，展示同类通用拒绝结果，不因对象是否存在而变化 |

### 2.4 不做什么（范围边界）

- **不做**受限对象摘要、名称、编号、状态或“对象不存在/存在但无权”的区分——避免利用错误信息确认对象存在性。
- **不做**采购计划可见范围之外的利润、推广、品退、售后及完整经营结果展示——本页不能成为权限旁路。
- **不做**角色申请、角色选择或业务侧角色编辑——三类角色映射由 IT 维护，产品没有权限管理后台。
- **不做**账号密码、注册、找回密码或共享账号入口——钉钉是唯一统一身份入口。
- **不做**把事业部负责人或未知角色自动赋为运营——无有效映射必须默认拒绝。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 已通过钉钉认证但无有效角色映射的内部用户；访问超出职责范围内容的运营、运营主管或采购计划；登录态已失效的原登录用户 |
| 人数 | 单次使用 1 人 |
| 技术熟练度 | 中等，能使用钉钉和内部 PC 系统，但不要求理解权限模型 |
| 使用设备 | 公司 PC 浏览器，主画布按 1440px、最低 1280px 使用 |
| 使用姿势 | 从工作台、清单、批次、追溯入口点击，或粘贴/收藏业务直链访问 |

### 3.2 核心使用场景

**场景 A：采购访问无关联建议（主场景）**

- 时机：采购计划通过直链或历史入口访问一条不包含分配给自己的补货/禁补任务的建议。
- 前置条件：用户钉钉登录态有效，角色为采购计划，但目标内容不在其授权任务范围内。
- 用户动作：打开链接 → 系统拒绝访问 → 用户选择“返回工作台”。
- 用户情绪：原本困惑或担心链接失效，希望明确知道无法访问，同时不被展示无关经营信息。

**场景 B：钉钉身份没有业务角色映射（兜底场景）**

- 时机：用户完成钉钉认证后，系统没有读取到 IT 配置的运营、运营主管或采购计划唯一有效角色。
- 前置条件：钉钉身份认证成功，但业务角色映射缺失或无效。
- 用户动作：看到“未配置业务角色”的通用说明 → 选择重新登录排除登录态问题，或按指引联系 IT。
- 用户情绪：希望知道由谁处理，不希望陷入反复登录却没有结论的循环。

**场景 C：会话失效后访问业务页（兜底场景）**

- 时机：用户停留较久后继续访问业务页，或使用旧收藏链接进入系统。
- 前置条件：原登录态已失效，系统不能继续确认当前权限。
- 用户动作：看到登录态失效说明 → 重新发起钉钉认证 → 认证成功后进入角色化工作台。
- 用户情绪：希望快速恢复访问，并确认失效期间没有泄露业务内容。

### 3.3 用户核心诉求（优先级排序）

1. **安全**：拒绝页面不能泄露目标建议、历史记录或经营字段。
2. **明确**：知道当前应返回工作台、重新登录还是联系 IT。
3. **一致**：从页面入口、直链或历史入口访问时得到一致结果，不因入口不同而暴露额外信息。
4. **可恢复**：合法用户可在一次操作内回到安全入口，不必猜测浏览器地址。

## 4. 信息架构

### 4.1 区域划分

1. 产品识别区
2. 拒绝结果区
3. 恢复操作区
4. 辅助说明区

### 4.2 区域内容

**1. 产品识别区**

- 产品名称。
- 当前为内部经营系统的说明。

**2. 拒绝结果区**

- 通用标题：“当前无法访问此内容”。
- 按安全原因分类显示说明：未配置业务角色、当前账号无访问权限、登录状态已失效。
- 不显示原访问对象的名称、ID、类型、状态、业务字段或是否存在。

**3. 恢复操作区**

- “返回工作台”：仅在当前登录态有效且用户有有效角色映射时提供。
- “重新登录”：用于会话失效、用户希望重新确认身份，或无角色映射时重新发起钉钉认证。
- “联系 IT”：用于角色映射缺失或持续无法访问；只提供职责指引，不在本页增加未确认的联系方式或工单功能。

**4. 辅助说明区**

- 说明角色由 IT 维护，产品内不能自行选择或更改。
- 提醒用户不要通过反复修改直链尝试访问未授权内容。

## 5. 界面内容

### 5.1 元素清单

**产品名称**

- 内容：趣然 AI 商品经营与利润决策助手。
- 文案：产品正式名称。
- 数据来源：产品配置。
- 显示条件：页面可完成基础加载时始终显示。

**拒绝标题**

- 内容：统一拒绝访问结果。
- 文案：“当前无法访问此内容”。
- 数据来源：当前访问控制结果。
- 显示条件：无有效角色映射、无页面/对象权限或会话失效时显示。

**拒绝说明**

- 内容：仅解释恢复方向，不描述受限对象。
- 文案规则：
  - 无角色映射：“当前账号未配置有效业务角色，请联系 IT。”
  - 无访问权限：“当前账号无权访问此内容，请返回工作台。”
  - 会话失效：“登录状态已失效，请重新使用钉钉登录。”
  - 无法安全判定原因：“暂时无法确认访问权限，请稍后重试或重新登录。”
- 数据来源：服务端返回的粗粒度拒绝原因类别。
- 显示条件：与当前安全原因对应；不得附带目标对象字段、上游错误明细或内部权限规则。

**返回工作台**

- 内容：进入当前角色的 `PAGE-F05-01`。
- 文案：“返回工作台”。
- 数据来源：当前登录态与有效角色映射结果。
- 显示条件：登录态有效且存在有效业务角色；否则不显示。

**重新登录**

- 内容：前往 `PAGE-F07-01` 重新发起钉钉认证。
- 文案：“重新登录”。
- 数据来源：认证恢复能力。
- 显示条件：会话失效时作为主恢复动作；其他拒绝状态下作为次要恢复动作。

**联系 IT 指引**

- 内容：提示角色映射和接入问题由 IT 处理。
- 文案：“如需开通或核对业务角色，请联系 IT。”
- 数据来源：上游确认的角色配置责任。
- 显示条件：无有效角色映射或用户连续无法恢复访问时显示。

**重试权限检查**

- 内容：重新确认当前登录态和访问权限，不提交任何业务变更。
- 文案：“重试”。
- 数据来源：当前认证与权限结果。
- 显示条件：权限检查因网络或系统异常未得到确定结果时显示；明确无权限时不以重试替代返回或联系 IT。

### 5.2 辅助信息

- 内部系统说明：“仅限已授权的趣然内部用户使用。”
- 角色责任说明：“业务角色由 IT 维护，产品内不可自行修改。”
- 本页不显示原始 URL 查询参数、目标资源摘要、内部错误码、钉钉票据或联系方式详情。

## 6. 交互流程

### 6.1 页面加载与初始化

1. 用户被导航到本页后，系统先确认当前登录态及是否存在有效业务角色。
2. 权限判定完成前只显示安全加载状态，不渲染被拒绝业务页的缓存、标题、面包屑、数量或对象摘要。
3. 根据结果进入无角色映射、无访问权限、会话失效或暂时无法判定四类状态。
4. 原访问地址只用于本次权限判断；页面不回显其路径参数，也不将其作为重新登录后的自动跳转目标。

### 6.2 核心操作流程

```text
用户访问业务入口或直链
    │
    ▼
系统校验登录态、角色映射与当前访问权限
    │
    ├─ 会话失效
    │    └─ 不返回经营数据 → 展示重新登录 → 前往钉钉登录页
    │
    ├─ 无有效角色映射
    │    └─ 默认拒绝 → 展示联系 IT 与重新登录
    │
    ├─ 有角色但无页面/对象权限
    │    └─ 展示通用无权限结果 → 返回角色化工作台
    │
    ├─ 网络或系统异常，无法安全判定
    │    └─ 保持拒绝 → 展示重试或重新登录
    │
    └─ 权限已恢复
         └─ 不回到原受限对象 → 进入角色化工作台
```

### 6.3 辅助操作

- 点击“返回工作台”只进入当前角色工作台，不回退到可能仍包含受限信息的上一页缓存。
- 点击“重新登录”进入钉钉登录页；认证完成后按最新角色进入工作台，不自动恢复原受限直链。
- 点击“重试”期间不可重复触发；得到结果后按最新会话与角色状态刷新本页结果。
- “联系 IT”仅给出职责指引，不在 MVP 内创建角色申请、工单提交或权限配置流程。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 权限检查中 | 页面首次进入，尚未得到安全判定 | 仅显示产品名称与“正在确认访问权限”；不展示原业务页缓存或对象信息 |
| 无角色映射 | 钉钉认证有效，但 IT 未配置唯一有效业务角色 | 显示未配置角色说明、重新登录和联系 IT；不显示工作台入口 |
| 无访问权限 | 用户有有效角色，但无目标页面或对象权限 | 显示通用无权限说明及返回工作台；不区分对象不存在与存在但无权 |
| 会话失效 | 登录态失效或无法继续认证当前用户 | 显示登录状态失效与重新登录；不展示任何经营数据 |
| 重新检查中 | 用户在暂时无法判定状态点击“重试” | 显示检查中并禁止重复触发，继续保持业务数据不可见 |
| 权限已恢复 | 重试或重新认证后获得有效登录态与角色 | 进入角色化工作台，不自动打开原受限目标 |
| 检查失败 | 网络、认证依赖或权限服务暂时不可用 | 显示“暂时无法确认访问权限”，提供重试与重新登录；默认拒绝 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 网络异常 | 权限校验超时或断网时默认拒绝，不渲染业务缓存；显示通用检查失败和“重试” |
| 会话过期 | 立即停止业务内容展示，进入会话失效状态；重新登录后进入工作台，不自动返回原受限对象 |
| 连续错误 | 用户连续访问不同受限直链或重复得到拒绝时，始终返回同类通用文案，不逐次增加对象、字段或权限规则细节；提示返回工作台或联系 IT |
| 异常输入 | 原地址含畸形、过长或无法识别的对象标识/查询参数时，不在页面回显输入，不用“对象不存在”确认其有效性，按通用无权限或无法安全判定处理 |
| 并发操作 | 本页打开后若 IT 修改角色或用户在其他窗口重新登录，下一次重试/跳转按最新服务端登录态与角色判断；旧页面结果不得继续授权 |
| 采购访问无关联建议 | 不返回建议身份、审核状态或任何经营字段，只展示通用无权限结果 |
| 采购探测受限字段 | 通过页面、筛选、错误或历史路径请求利润、推广、品退、售后时均不返回字段，错误文案不点名具体字段是否存在 |
| 用户拥有有效采购任务 | 本页不承担裁剪详情展示；应进入有权限的采购版建议详情，由对应页面仅显示任务必要投影 |
| 浏览器返回上一页 | 若上一页已失权或会话失效，重新校验后仍阻断；不得仅依赖浏览器缓存恢复业务内容 |
| 原目标已删除或从未存在 | 与“对象存在但无权”使用同一通用结果，不提供可区分的标题、状态或恢复路径 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| `access_outcome` | 当前安全判定结果，仅取“无角色映射、无访问权限、会话失效、暂时无法判定、权限已恢复”中的一项 |
| `session_valid` | 当前钉钉关联登录态是否仍有效，仅用于选择恢复路径 |
| `role_mapping_valid` | 是否存在由 IT 维护的唯一有效运营、运营主管或采购计划角色映射；本页不允许用户修改 |
| `can_return_workspace` | 当前用户是否可安全进入角色化工作台 |
| `recovery_action` | 当前可用恢复动作：返回工作台、重新登录、重试或联系 IT 指引 |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 登录态 | 页面初始化、重试与任一跳转前 | 登录态失效时不得进入业务页或返回经营数据 | “登录状态已失效，请重新使用钉钉登录。” |
| 角色映射 | 钉钉认证成功后及后续权限检查 | 必须存在 IT 配置的唯一有效运营、运营主管或采购计划角色；不得自动赋默认角色 | “当前账号未配置有效业务角色，请联系 IT。” |
| 页面/对象权限 | 访问业务路由、建议或历史记录时 | 按当前服务端角色及任务关联判断；无权时默认拒绝 | “当前账号无权访问此内容，请返回工作台。” |
| 采购最小可见 | 采购访问页面、筛选、错误或历史记录时 | 仅有权任务可进入裁剪详情；无任务关联时不返回建议身份、状态及受限字段 | 使用通用无权限文案，不列出被拦截字段或目标信息 |
| 恢复目标 | 点击返回或重新登录成功后 | 只进入当前角色工作台，不自动打开原受限对象 | 无有效角色时不展示“返回工作台” |
| 原地址参数 | 页面初始化时 | 不回显、拼接或解释原始对象标识及异常查询参数 | 使用通用拒绝结果，不显示原始输入 |

### 8.3 特殊业务规则

- **默认拒绝**：未知角色、无角色、会话状态不明或权限服务异常时均不得开放业务数据。
- **对象存在性保护**：对象不存在、对象存在但无权、无任务关联三种情况不能通过标题、说明、状态或响应时机形成可见差异。
- **采购最小投影**：采购只有在建议包含分配给自己的补货/禁补任务且有访问权时，才能进入采购裁剪详情；本页本身不展示任何任务投影。
- **角色来源唯一**：业务角色只读取 IT 维护的映射结果；本页没有角色切换、申请、编辑或临时授权能力。
- **最新权限优先**：角色或登录态变化后，后续跳转必须按最新判定；旧页面状态不构成继续访问依据。

## 9. 页面流转

### 9.1 流转图

```text
钉钉登录 / 任一业务页 / 业务直链 / 历史入口
                    │
                    ▼
             权限检查未通过
                    │
                    ▼
        PAGE-F07-02 无权限（本页）
          │            │            │
          │            │            └─ 映射缺失/持续失败 → 联系 IT
          │            └─ 会话失效 → PAGE-F07-01 钉钉登录
          └─ 有有效角色 → PAGE-F05-01 角色化工作台

重新认证或权限恢复后只进入工作台，不自动返回原受限对象。
```

### 9.2 与其他模块的关系

- **认证模块**：接收钉钉登录态是否有效与角色映射结果；会话失效时流转到 `PAGE-F07-01`。
- **角色化工作台**：作为有效角色用户离开本页后的安全入口；本页不携带原受限对象数据进入工作台。
- **建议与追溯模块**：越权访问统一由本页承接；若采购确有被分配的补货/禁补任务，应由建议详情或历史页返回最小必要投影，而不是先展示本页再泄露摘要。
- **数据批次与行动清单**：无权访问时不显示批次编号、数量、清单状态或任何缓存内容。
- **IT 角色维护**：本页只说明责任归属，不提供产品内配置入口。

### 9.3 扩展预案

| 扩展方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 产品内角色申请 | 上游正式新增角色申请流程、审批责任和稳定 REQ/AC | 新增独立申请页面；本页仅增加已确认入口，不直接承担申请表单 |
| 新业务角色 | 上游确认新角色的数据边界与操作职责 | 扩展角色映射和工作台去向；未知角色仍默认拒绝 |
| 多事业部授权 | 上游明确事业部范围、跨事业部权限与错误信息约束 | 权限判定增加事业部范围，但本页继续不显示受限事业部或对象身份 |
| 权限审计自助查看 | 上游确认谁可查看拒绝记录及其字段范围 | 新增独立审计页面；不得向普通用户展示内部授权规则或受限对象信息 |

## 10. 数据需求

### 10.1 页面需要什么数据

| 数据 | 来源 | 用途 |
| :--- | :--- | :--- |
| 产品名称 | 产品配置 | 让用户确认当前所在系统 |
| 登录态有效性 | 钉钉关联的产品登录态 | 决定是否引导重新登录 |
| 角色映射有效性 | IT 维护的业务角色映射结果 | 区分无角色映射与有角色但无访问权，并决定是否可返回工作台 |
| 粗粒度访问结果 | 当前访问控制结果 | 选择安全拒绝说明；不包含对象身份、状态或受限字段 |
| 可用恢复动作 | 当前登录态与角色结果 | 只显示当前可执行的返回、重新登录、重试或联系 IT 指引 |

### 10.2 页面提交什么数据

| 数据 | 触发时机 | 用途 |
| :--- | :--- | :--- |
| 无业务表单数据 | 始终 | 本页只进行导航与权限重检，不创建、修改或删除任何批次、建议、审核、动作或结果 |
| 权限重新检查意图 | 用户点击“重试” | 按最新登录态和角色重新判断安全去向，不携带原受限对象摘要 |
| 重新认证意图 | 用户点击“重新登录” | 前往钉钉登录页重新确认身份，不提交账号密码或角色选择 |

### 10.3 明确排除的数据

- 不需要也不得返回目标对象的 SPU ID、名称、店铺、平台、责任运营、建议 ID、批次 ID 或规则版本。
- 不需要也不得返回目标对象的审核状态、经营动作状态、采购动作状态、事件时间线或 AI 状态。
- 不需要也不得返回完整利润、推广、品退、售后、经营结果或其他采购无权字段。
- 不需要钉钉认证票据、账号凭据、LiteLLM deployment secret、内部权限规则明细或错误堆栈。
- 不保留原始畸形地址参数作为页面展示内容，也不把原受限对象作为重新登录后的自动恢复目标。

## 11. 验收标准

### 11.1 功能验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 无角色映射 | 钉钉认证成功但无唯一有效业务角色时进入本页，不能进入业务页，显示联系 IT 与重新登录指引，且不出现工作台入口 |
| F-02 | 采购无任务关联 | 采购直访不属于其补货/禁补任务的建议或历史记录时，只显示通用无权限结果，不显示建议身份或状态字段 |
| F-03 | 会话失效 | 登录态失效后访问任一业务页时进入会话失效状态，可前往 `PAGE-F07-01`，页面不保留原业务内容 |
| F-04 | 返回工作台 | 有有效登录态与角色但无目标权限时，“返回工作台”进入 `PAGE-F05-01`，不返回原受限对象 |
| F-05 | 权限恢复 | IT 修正角色或重新登录后再次检查权限，系统按最新权限进入角色化工作台；旧拒绝结果不继续授权或阻断 |
| F-06 | 异常检查恢复 | 网络导致权限结果无法确认时保持默认拒绝；点击“重试”只发起一次重新检查，并按新结果更新安全去向 |

### 11.2 体验验收

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| U-01 | 恢复路径明确 | 无角色映射、无访问权、会话失效和暂时无法判定四种状态均至少展示一个当前可用的恢复动作 |
| U-02 | 文案可理解 | 页面使用“未配置业务角色”“无权访问”“登录状态已失效”等用户可行动表述，不展示内部错误码、权限规则或技术堆栈 |
| U-03 | 不形成循环 | 重新登录成功后进入角色化工作台，不自动返回导致拒绝的原链接 |
| U-04 | 重试防重复 | 权限重新检查未完成前不能再次触发“重试”，页面持续显示正在确认访问权限 |
| U-05 | 入口一致 | 从导航、收藏直链、历史入口或浏览器返回进入同一无权目标时，页面标题、恢复动作和信息边界一致 |
| U-06 | 状态不混淆 | 网络异常显示“暂时无法确认访问权限”，不误报为“没有业务角色”或“对象不存在” |

### 11.3 安全验收（产品层）

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| S-01 | 对象存在性保护 | 分别访问一个真实但无权对象、一个不存在对象和一个畸形对象标识时，页面不显示可区分的对象名称、状态、摘要或错误细节 |
| S-02 | 采购字段隔离 | 采购通过页面、筛选、错误路径或历史入口触发本页时，页面内容中利润、推广、品退、售后和完整经营结果字段出现数为 0 |
| S-03 | 默认拒绝 | 无角色、未知角色、登录态不明或权限检查异常时均不能进入任何业务页，也不能看到缓存的业务标题、面包屑、数量或摘要 |
| S-04 | 无默认提权 | 无有效角色映射时系统不会自动赋予运营、主管或采购角色，本页也不存在角色选择或临时开通控件 |
| S-05 | 原地址不回显 | 原始受限 URL、对象标识和异常查询参数不出现在页面标题、正文、恢复链接或重新登录后的自动跳转目标中 |
| S-06 | 敏感信息不暴露 | 页面不显示钉钉票据、账号凭据、LiteLLM deployment secret、内部权限规则详情或错误堆栈；恢复文案只指向重新登录或联系 IT |
