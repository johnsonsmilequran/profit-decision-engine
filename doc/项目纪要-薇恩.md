# 薇恩 · 项目纪要

- 项目目标：为趣然电商建设“AI 商品经营与利润决策助手”，汇总周度 SPU 经营数据并生成可审核、可执行、可追踪的经营行动清单。
- 约束：遵循文档驱动、Design/TDD 契约与 Git 高频同步；只维护本纪要，不修改其他操作者的项目纪要；薇恩后续变更均在 `weien` 分支提交并推送，不直接推送 `main`；生产实现必须接入真实后端 API 与 PostgreSQL 持久化，禁止 mock、硬编码业务数据、假按钮和仅前端实现。
