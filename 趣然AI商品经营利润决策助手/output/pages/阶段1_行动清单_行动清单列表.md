# 页面名称：行动清单列表

## 1. 文档元信息
| 字段 | 内容 |
| :--- | :--- |
| 页面 ID | `PAGE-F05-01` |
| Source IDs | `REQ-F05-01, REQ-F05-02, REQ-F05-03, AC-F05-01, AC-F05-03, AC-F05-04, AC-F05-05` |
| 所属产品 | 趣然 AI 商品经营与利润决策助手 |
| 所属模块 | 行动清单 |
| 适用端 | PC Web（最小宽度 1024px） |
| 页面路由 | `/action-lists/:batchId` |
| 页面类型 | 列表 |
| 所属阶段 | 阶段1(MVP) |
| 上游来源 | 角色待办工作台、批次详情、历史追溯索引 |
| 下游去向 | 建议详情、批次详情 |

## 2. 页面概述
### 2.1 一句话定位
展示一个批次唯一的可行动建议投影，按清仓、止损、观察、加投、补货固定层级排序，并按角色提供服务端分页与筛选。

### 2.2 存在理由
1. 把分散 SPU 数据变成周度可执行入口而非重复清单实体。
2. 固定排序让高风险动作先处理，AI 不改变业务优先级。
3. 将审核与两类动作状态并列展示，及时暴露跨部门进度差异。

### 2.3 页面目标（可衡量）
| 维度 | 指标 |
| :--- | :--- |
| 唯一性 | 每个 batch_id 仅一份行动清单 |
| 完整性 | 100% 建议包含对象、问题、关键依据、推荐动作 |
| 可操作 | 授权用户可在 2 次点击内从清单进入责任操作入口 |

### 2.4 不做什么（范围边界）
- 不批量审核、批量执行、导出或无限滚动——首版无 Source IDs。
- 不收录纯维持且无补货/禁补的 SPU。
- 不为“不补货”单独创建采购执行任务。
- 不出现广告计划、关键词、素材、退款原因、评价主题或 SKU 对象。

## 3. 用户与场景
### 3.1 目标用户
| 角色 | 使用方式 |
| :--- | :--- |
| 运营主管 | 筛选待审核建议并进入完整详情 |
| 运营 | 处理经营动作、结果和查看完整经营依据 |
| 采购计划 | 只查看补货/禁补任务及库存销量必要依据 |

### 3.2 核心使用场景
**场景 A：处理本周高风险建议（主场景）**
- 时机：固定规则完成并形成唯一清单
- 前置：batch_id 有权访问且清单就绪
- 动作：按默认层级浏览 → 筛选本人待办 → 进入建议详情
- 情绪：聚焦、可行动

**场景 B：筛选无结果或 AI 失败（兜底场景）**
- 时机：条件过窄、AI 解释失败或网络加载异常
- 前置：批次存在
- 动作：清除筛选，继续使用结构化四要素；加载失败时原条件重试
- 情绪：不被 AI 或加载问题阻塞

### 3.3 用户核心诉求（优先级排序）
1. 高风险动作始终排在前面。
2. 筛选本人责任且刷新后条件不丢失。
3. 同一 SPU 的经营与库存动作不被拆成两条建议。
4. AI 失败仍能看懂并执行固定规则建议。

## 4. 信息架构
### 4.1 区域划分
1. 应用壳与面包屑；2. 批次摘要；3. 风险/状态计数；4. 搜索与筛选；5. 建议表格；6. 服务端分页。

### 4.2 区域内容
- 批次摘要：事业部、完整自然月、截止日、规则版本、质量限制。
- 筛选：主动作/采购动作、店铺、责任运营、审核状态、执行状态。
- 列表：对象、问题摘要、关键依据摘要、利润—库存双轨动作、审核/两动作状态、数据限制、AI 状态、详情入口。

## 5. 界面内容
### 5.1 元素清单
- **批次选择/返回详情**：明确当前 batch_id，不在本页生成第二清单。
- **筛选器**：字段候选按角色裁剪，条件写入 URL。
- **建议行**：一条 SPU 一条整体建议，加投与补货可双轨并存。
- **排序说明**：固定动作层级；同层使用规则版本已声明且校验的代理，否则稳定 SPU ID。
- **数据限制/AI 标记**：AI 待生成/失败、品退未校验、库存不足等。
- **分页器**：默认每页 20 条，显示总数、页码和当前范围。

### 5.2 辅助信息
明确“AI 仅解释、不改变排序和动作”；采购页面不显示完整经营筛选、字段或推断性空值。

## 6. 交互流程
### 6.1 页面加载与初始化
解析 batch_id 与 URL 条件 → 校验角色 → 加载批次摘要和第一页 → 默认固定层级排序。

### 6.2 核心操作流程
```text
选择筛选 → 服务端返回匹配建议 → 点击建议 → 进入裁剪后的建议详情
切换页码 → 保留所有筛选和 batch_id
清除筛选 → 回第一页并恢复完整有权清单
```

### 6.3 辅助操作
从工作台进入时采用预置角色筛选；浏览器返回恢复 URL 条件；不在列表内直接更改审核或执行状态。

## 7. 状态与边界
### 7.1 页面状态全景
| 状态 | 页面表现 |
| :--- | :--- |
| 加载 | 保留批次与筛选结构，列表显示加载中 |
| 正常 | 建议按固定层级和稳定次序分页显示 |
| 筛选无结果 | 显示当前条件无建议并可清除筛选 |
| 清单未就绪 | 显示批次处理阶段并返回批次详情 |
| AI 待生成/失败 | 结构化四要素照常显示且详情可进入 |
| 加载失败/无权限 | 显示原 batch_id 重试；越权不返回建议身份 |

### 7.2 边界与容错
| 边界 | 策略 |
| :--- | :--- |
| 网络异常 | 原筛选和页码重试，不误显示零建议 |
| 会话过期 | 返回钉钉门禁，不缓存可见经营字段 |
| 连续查询错误 | 保留批次摘要并显示失败，不降级为本地未裁剪数据 |
| 异常筛选输入 | 拒绝未知字段/状态，返回可修正提示 |
| 并发状态变化 | 列表刷新显示最新状态，详情提交仍校验 version |
| 历史批次 | 所有进入详情与操作均绑定原 batch_id，不写入新批次 |

## 8. 业务规则与校验
### 8.1 字段定义
| 字段 | 说明 |
| :--- | :--- |
| `main_action` | 唯一经营主动作 |
| `replenishment_action` | 补货、不补货、禁补或不生成 |
| `review_state` | 待审核、已通过或已驳回 |
| `execution_summary` | 由分动作状态只读聚合的建议总览 |
| `stable_order_key` | 同动作层稳定代理或 SPU ID |

### 8.2 校验规则
| 校验 | 时机 | 失败反馈 |
| :--- | :--- | :--- |
| batch_id 存在且清单就绪 | 初始化 | 返回批次详情查看处理状态 |
| 筛选字段有权 | 查询 | 条件无效/权限不足 |
| 页码有效 | 查询 | 回第一页并更新 URL |
| 建议有权 | 打开详情 | 权限不足且不返回建议身份 |

### 8.3 特殊业务规则
- 默认层级为清仓＞止损＞观察＞加投＞补货；AI 不参与层级或代理结果。
- 加投与补货并存时仍为一条建议；止损/清仓与禁补同显。
- 纯维持无补货/禁补不收录；不补货不创建采购任务。

## 9. 页面流转
### 9.1 流转图
```text
工作台/批次详情/历史追溯 → 本页 → 建议详情 → 审核或责任动作表单
                              └→ 批次详情
```

### 9.2 与其他模块的关系
本页是 F05 唯一清单投影，读取 F03/F04 结论、F06 状态和 F07 权限；完整溯源由建议详情承载。

### 9.3 扩展预案
| 方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
| 更多代理指标 | 新规则版本明确可解释代理 | 按版本显示并排序，不重排历史规则结果 |
| 外部动作回执 | 阶段2正式 REQ | 挂接稳定 action_id，不改变人工事件 |

## 10. 数据需求
### 10.1 页面需要什么数据
批次摘要、裁剪后的建议分页、四要素摘要、双轨动作和状态、质量/AI 标记、筛选候选与总数。

### 10.2 页面提交什么数据
batch_id、搜索/筛选、固定排序键和页码；本页不提交审核、执行或结果状态。

### 10.3 明确排除的数据
不需要原始 XLSX、部署密钥、AI 推测排序、批量操作数据；采购不需要利润、推广、品退、售后或完整 AI 文本。

## 11. 验收标准
### 11.1 功能验收
| 编号 | 通过标准 |
| :--- | :--- |
| F-01 | 每个 batch_id 仅显示一份清单且历史不被新批次覆盖 |
| F-02 | 默认按清仓、止损、观察、加投、补货固定层级排序 |
| F-03 | 动作、店铺、责任运营、审核和执行筛选返回匹配建议 |
| F-04 | 纯维持无补货/禁补不出现，不补货不创建采购任务 |
| F-05 | AI 等待/失败时四要素和详情入口仍可用 |

### 11.2 体验验收
| 编号 | 通过标准 |
| :--- | :--- |
| U-01 | 筛选和页码写入 URL，刷新与返回可恢复 |
| U-02 | 默认每页 20 条并显示当前范围和总数 |
| U-03 | 筛选无结果与加载失败视觉和文案明确区分 |
| U-04 | 双轨动作与两类执行状态在同一建议行可辨 |
| U-05 | 1024px 及以上核心语义不截断，完整内容可进入详情 |

### 11.3 安全验收（产品层）
| 编号 | 通过标准 |
| :--- | :--- |
| S-01 | 无登录态或无权 batch_id 不返回建议列表 |
| S-02 | 采购只收到补货/禁补任务及库存销量必要依据 |
| S-03 | 采购筛选候选、URL、错误和列表均无受限经营字段 |
| S-04 | 非主管、非责任角色的操作入口不显示且请求被拒绝 |
| S-05 | 页面不出现 deployment secret、模型配置或内部调用详情 |
